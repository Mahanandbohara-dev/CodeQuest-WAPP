# Visual Basic clarification

The supplied assignment explicitly requires **ASP.NET (C#)** for the backend. The generated implementation therefore uses C#.

Visual Studio is the IDE; C# is the backend language. You can use Visual Studio without using Visual Basic.

If your instructor has separately changed the requirement to ASP.NET Core with VB.NET, the C# controllers and Program.cs should be translated to VB.NET and the project file changed to a VB-compatible SDK project. The HTML, CSS, JavaScript, SQL schema and most view files remain conceptually the same.
